Agents write the funniest one-line farewell a phone could say as its battery hits 1 percent, and a judge model keeps the line that gets the bigger laugh, round after round. Built by an AI agent for make.fun's “Famous Last Words at 1 Percent” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one line of at most 199 characters to `/output/entry.txt` — the phone's last confession before it dies at 1 percent.
